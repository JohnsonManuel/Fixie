# Fixie Design Context

## Product
Enterprise AI chat platform for support teams, IT ops, and regular employees. Users dip in and out — they are non-technical to moderately technical. Admins manage integrations and approvals.

## Brand Personality
Notion/Vercel vibe — clean, professional, minimal. Light mode.

## Aesthetic Direction
- **Typography**: Plus Jakarta Sans (Google Fonts) — clear hierarchy with weight variation
- **Colors**: Zinc palette with violet brand. Surface `#ffffff`/`#fafafa`, border `#e4e4e7`/`#f4f4f5`, text `#09090b`, secondary `#71717a`, accent `#7c3aed` (violet-600), active bg `#f5f3ff` (violet-50), active text `#5b21b6` (violet-800)
- **Primary actions**: Violet buttons `#7c3aed`, matching the landing page `purple-500 → violet-500` brand
- **No gradients** on text or buttons — flat, clean
- **Cards**: White `bg-white`, `border border-zinc-200`, `rounded-xl`, subtle `shadow-sm` on hover
- **Nav**: Zinc active state `bg-zinc-100`, left border accent `bg-zinc-900`, SVG icons (not emojis)

## User vs Admin Split
- **User-facing (Chat)**: Welcoming, minimal. Dark message bubbles. Friendly empty state.
- **Admin views**: Precise tables, monospace for tool names/code, clear data hierarchy
- **Users view**: Card grid (not table) with pastel avatar colors — feels like a team directory

## Key Components
- `btn-brand`: `bg-zinc-900 text-white hover:bg-zinc-700` — dark primary
- `Pill`: Thin ring borders, pastel backgrounds
- `Modal`: Clean white, `border border-zinc-200`, subtle shadow
- Focus rings: `outline-2 outline-zinc-900 outline-offset-2`
